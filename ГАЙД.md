# 🧭 ГАЙД по сайту «Капитан Константин»

Простая инструкция: где что лежит и как менять самому. Технических знаний не требует — почти всё меняется в **двух файлах**.

---

## ⚡ Главное за 30 секунд

| Что поменять | Где | Файл |
|---|---|---|
| **Тексты** (заголовки, описания, цены, телефон, FAQ) | почти всё | `src/data/content.js` |
| **Цвета и шрифты** | палитра сайта | `src/index.css` (блок `@theme` сверху) |
| **Фотографии** | картинки | папка `public/img/` + пути в `content.js` |
| **Заголовок вкладки / описание для Google** | — | `index.html` |
| **Порядок секций** | — | `src/App.jsx` |

> Правило №1: меняйте только текст **в кавычках** `"вот так"`. Запятые, скобки и слова на латинице не трогайте.
> Правило №2: после правки **сохраните файл** — сайт обновится сам (если запущен `npm run dev`).

---

## 🚀 Как запустить сайт у себя

Сайт — это приложение (React + Vite), поэтому открыть `index.html` двойным кликом **нельзя**. Нужен локальный сервер. В Терминале, находясь в папке проекта:

```bash
npm install      # один раз — установить зависимости
npm run dev      # запустить сайт; откроется адрес http://localhost:5173
```

Открываете показанный адрес в браузере. Пока команда работает — правки в файлах видны сразу.
Остановить: `Ctrl + C` в Терминале.

## ✍️ Как поменять ТЕКСТ

Почти все тексты — в файле **`src/data/content.js`**. Он разбит на понятные списки:

- `CONTACT` — телефон, телеграм, адрес, лицензия, цена за час
- `NAV` — пункты верхнего меню
- `STATS` — три цифры под главным экраном
- `AMENITIES` — список «На борту»
- `ROUTES` — 4 карточки маршрутов
- `FORMATS` — 6 карточек «Форматы прогулок»
- `SERVICES` — список услуг с ценами
- `ETIQUETTE` — «Этикет на борту»
- `FAQ` — вопросы и ответы
- `GALLERY` — фотографии галереи

**Пример** — поменять телефон: найдите в `CONTACT` строки и впишите свой номер:
```js
phone: "+7 911 990 8089",   // как показывается на экране
phoneRaw: "79119908089",    // ТОЛЬКО ЦИФРЫ — для звонка и WhatsApp
```

**Заголовок главного экрана и текст «о капитане»** написаны прямо в компонентах:
- главный экран → `src/components/Hero.jsx`
- о капитане → `src/components/Captain.jsx`

## 🎨 Как поменять ЦВЕТА

Все цвета заданы один раз в **`src/index.css`**, в блоке `@theme` в самом верху. Поменяли цвет тут — он сменится по всему сайту.

```css
--color-deep: #ffffff;    /* ГЛАВНЫЙ ФОН (сейчас белый) */
--color-ice: #0d2231;     /* цвет заголовков */
--color-mist: #45616e;    /* цвет обычного текста */
--color-teal: #0d9488;    /* основной акцент — бирюза */
--color-gold: #9c6f1a;    /* второй акцент — золото */
```

Цвет в формате `#RRGGBB`. Подобрать: в Google наберите «color picker», скопируйте HEX-код.

Примеры:
- **Кремовый фон вместо белого:** `--color-deep: #faf8f3;`
- **Другой акцент** (например, синий): `--color-teal: #2563eb;`

> Важно: `--color-abyss` (тёмный) — это затемнение поверх фото и фон при увеличении картинок. Его белым делать **не нужно**.

Кнопки имеют свой яркий градиент — он чуть ниже в том же файле, класс `.btn-aqua`.

## 🔤 Как поменять ШРИФТ

1. В `index.html` поменяйте ссылку на шрифты Google Fonts (строка с `fonts.googleapis.com`).
2. В `src/index.css` (блок `@theme`) впишите новые названия:
```css
--font-display: "Sora", sans-serif;   /* заголовки */
--font-sans: "Inter", sans-serif;     /* текст */
```

---

## 🖼 Как поменять ФОТО

1. Положите новый файл в папку **`public/img/`** (например `my-photo.jpg`).
2. Впишите путь к нему там, где нужно:
   - маршруты и галерея → в `src/data/content.js` (поля `img` / `src`), путь вида `"img/my-photo.jpg"`;
   - фото катера, капитана, главного экрана → прямо в компонентах `Boat.jsx`, `Captain.jsx`, `Hero.jsx` (атрибут `src=`).

> Путь пишется как `img/имя.jpg` (без папки `public` и без слэша в начале).
> К каждому фото есть `alt` — короткое описание. Его стоит заполнять (важно для Google и доступности).

## 🧩 Из чего состоит сайт (секции)

Каждая секция — отдельный файл в `src/components/`:

| Файл | Секция на сайте |
|---|---|
| `Header.jsx` | Шапка с меню |
| `Hero.jsx` | Главный экран |
| `Boat.jsx` | Катер |
| `Captain.jsx` | Капитан |
| `Routes.jsx` | Маршруты |
| `Formats.jsx` | Форматы прогулок |
| `Services.jsx` | Услуги |
| `Gallery.jsx` | Галерея |
| `Faq.jsx` | Вопросы и ответы |
| `Contact.jsx` | Контакты + форма |
| `Footer.jsx` | Подвал |
| `FloatingCta.jsx` | Плавающая кнопка |

**Порядок секций** задаётся в `src/App.jsx` — переставьте строки внутри `<main>`, чтобы поменять порядок. Чтобы убрать секцию — удалите её строку.

Внутри компонентов есть подробные комментарии к каждому блоку и ключевым классам.

## 🛠 Подсказки по классам оформления (Tailwind)

Оформление задаётся «классами» прямо в `className="..."`. Самые частые:

| Класс | Что делает |
|---|---|
| `text-ice` / `text-mist` | цвет текста: тёмный / приглушённый |
| `text-teal` / `text-gold` | акцентный текст: бирюза / золото |
| `text-[1.3rem]` | размер текста (1.3rem ≈ 21px) |
| `font-semibold` / `font-display` | жирность / шрифт заголовков |
| `mt-5` `mb-4` `px-6` `py-3` | отступы (m = снаружи, p = внутри; t/b/l/r/x/y — сторона) |
| `rounded-2xl` | скругление углов |
| `glass` / `glass-strong` | матовое стекло (карточки) |
| `btn-aqua` | стиль главной кнопки |

Числа в отступах — это шаг (1 ≈ 4px): `mt-2` ≈ 8px, `mt-8` ≈ 32px.

## 🌍 Как опубликовать сайт (на kapitankonstantin.ru)

1. Собрать готовую версию:
```bash
npm run build
```
2. Появится папка **`dist/`** — это и есть готовый сайт.
3. Содержимое `dist/` загрузите на хостинг (туда же, где сейчас сайт).

Проверить собранную версию локально перед загрузкой:
```bash
npm run preview
```

## ❗ Если что-то сломалось

- Сайт стал белым/пустым → скорее всего лишняя или удалённая запятая/кавычка в `content.js`. Проверьте последнюю правку.
- Не уверены в правке → скопируйте файл перед изменением, чтобы вернуть как было.
- Папка `legacy/` хранит старую версию сайта — она не участвует в новой, но лежит на всякий случай.

Удачи! Почти всё, что нужно для жизни сайта, — это `content.js` (тексты) и `index.css` (цвета).
